# benchmark

基准测试模块，用于复现论文结果、评估 LLM 和添加自定义任务。

## 包含的基准

- [biomed/](biomed/) - 生物医学问答
- [chem/](chem/) - 化学分析
- [demo/](demo/) - 演示基准
- [instruct_follow/](instruct_follow/) - 指令跟随
- [instruct_pretrain/](instruct_pretrain/) - 指令预训练
- [long_context/](long_context/) - 长文本理解
- [math/](math/) - 数学问题
- [physics/](physics/) - 物理推理
